# Project Overview

This project presents the design and prototype of a modern, user-friendly mobile/web application created using *Figma*.

The Hospital Appointment System enables patients to conveniently book medical appointments online, reducing waiting times and improving access to healthcare services.

The application was designed following UI/UX design principles, including:

* User research
* Wireframing
* High-fidelity interface design
* Interactive prototyping
* Accessibility best practices
* Responsive design

The objective is to provide patients with a simple, efficient, and user-friendly platform for managing hospital appointments.

---

# Problem Statement

Many patients experience challenges when scheduling hospital appointments, including:

* Long waiting queues
* Difficulty contacting hospitals
* Missed appointments due to poor scheduling
* Lack of appointment reminders
* Limited access to doctors' availability

Our application addresses these issues by allowing patients to register, search for doctors, book appointments, receive confirmations, and manage their appointments through a simple and responsive interface.
